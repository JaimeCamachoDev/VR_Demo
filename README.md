# **VR_Demo**

_**Proyecto base para experiencias VR en Quest 3**_

</header>

## Requisitos

* Unity **6000.2.8f1**
* Render Pipeline: Universal Render Pipeline (URP)
* Paquetes: OpenXR, XR Hands

## Contenido

* **Shader Graph:** `CelShadeLit`, `Outline`, `Outliner`, `StrokeEffect_Graph`, `Toon Jaime MK_1`, `Toon Jaime MK_1 1`
* **Sub Graphs:** `LightingCelShadedNode`, `SpaceFog`
* **Shaders HLSL:** `LightingCelShaded`
* **Prefabs:** `Audio Source`, `Rick and Morty Garage`, `T-Pose`, `fd901017d0ee4b4eaef6184b5daa9617`
* **Escenas:** `Assets/3-Scenes/Main.unity`, `Assets/3-Scenes/Scene Chihiro.unity`, `Assets/3-Scenes/Scene rick morty demo.unity`

## Uso

1. Clona el repositorio y añádelo en Unity Hub (*Add project from disk*).
2. Ábrelo con Unity **6000.2.8f1**.
3. Abre la escena `Assets/3-Scenes/Main.unity` y pulsa **Play**.
